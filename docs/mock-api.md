# Mock API

The mock API is a small Fastify server in `mock-server/`. It replays three days of market data, **4–6 November 2026**, including the 5 November sell-off, so the UI works without paid data, API keys, or a private backend. Vite proxies `/api` to it on port 4000.

## Market data

| Data                                  | Source                    | In the repository                                                  |
| ------------------------------------- | ------------------------- | ------------------------------------------------------------------ |
| Daily and 5-minute prices             | Yahoo Finance             | No. Recorded locally, because Yahoo's terms forbid redistribution  |
| Fallback prices                       | Generated by the mock API | Generated at startup from `mock-server/src/syntheticMarketData.ts` |
| Quarterly revenue, annual diluted EPS | SEC EDGAR                 | Yes, in `mock-server/data/sec-fundamentals.json`                   |

`npm run mock-server:record-prices` records the real prices into the gitignored `mock-server/data/recorded/`. Yahoo Finance keeps 5-minute bars for only about 60 days, so the November 2026 window can be recorded until about early January 2027.

Without recorded prices, the mock API **generates synthetic prices** instead. They follow the same instruments, trading hours, and story, including the 5 November sell-off, and are the same on every start. Every response then labels the data as a synthetic replay, and the UI says that the prices are not real. To try them while recorded prices exist, start the mock API with `npm run mock-server -- --synthetic` and the UI with `npm run dev:ui`.

Yahoo Finance has no 5-minute or 1-minute bars for US instruments and EUR/USD between 17:15 and 18:50 UTC on 5 November. The next bar reports the volume of the whole gap, so the mock API leaves that bar's volume out and does not attribute price moves to the missing period.

To re-record SEC fundamentals, set `SEC_USER_AGENT` in `.env` (see `.env.example`); the SEC requires a name and contact email for automated requests. Then run `npm run mock-server:record-fundamentals`.

Instruments: S&P 500, Nasdaq-100, DAX, NVIDIA, AMD, Alphabet, Oracle, Eli Lilly, Strategy (MSTR), Bitcoin, and EUR/USD.

## Replay

The replay runs at 300× speed by default, one 5-minute bar per second, and starts again after 6 November. The clock lives in the mock API, so every browser tab follows the same replay. It can be paused, moved to any moment, or run at 60×, 150×, 300×, or 900×. Responses include the replay window, speed, pause state, and market time.

## Endpoints

| Endpoint                                    | Purpose                                                                                               |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `GET /api/market/snapshot`                  | Latest quotes at the current replay time                                                              |
| `GET /api/market/history?symbol=NVDA`       | 5-minute prices and volume of one instrument up to the current replay time                            |
| `GET /api/market/anomalies`                 | Unusual activity detected so far in the current replay                                                |
| `GET /api/market/stream`                    | SSE events: `quote.updated`, `anomaly.detected`, `replay.restarted`, `replay.changed`, `replay.clock` |
| `GET /api/opportunities`                    | Long/short screening of every instrument from completed daily closes and SEC fundamentals             |
| `GET /api/market/daily-history?symbol=NVDA` | A year of daily closes with 50- and 200-day averages, up to the latest screening                      |
| `GET /api/replay`                           | The replay window, speed, pause state, and current market time                                        |
| `PATCH /api/replay`                         | Pauses or resumes the replay, moves it to a market time, or sets its speed                            |

The contracts are Zod schemas in `src/contracts/`. The UI validates every response and stream event with them, and the mock API uses them for its types.

## Alert rules

Every alert states the rule behind it.

- **Price move:** the price changes within 30 minutes, or since the previous session, by at least 1% for indices, 3% for stocks, 2% for crypto, or 0.4% for currency pairs.
- **Heavy volume:** a stock's session volume reaches 1.5× its 20-day average daily volume. Index and crypto volume in the recorded data is not comparable with daily volume, and DAX and EUR/USD have none.

## Screening rules

Opportunity Radar's screening runs at midnight UTC of each replayed day. It uses only daily closes completed before that time and company reports filed before that day, so it never looks ahead. Four rules each point long, short, or neutral:

| Rule              | Long                                                     | Short                              | Applies to             |
| ----------------- | -------------------------------------------------------- | ---------------------------------- | ---------------------- |
| Trend             | Close above the 200-day average                          | Close below it                     | All instruments        |
| Relative strength | Three-month return beats the S&P 500 by 5 points or more | Trails it by 5 points or more      | All except the S&P 500 |
| Revenue growth    | 20% or more year over year                               | Shrinking revenue                  | Stocks                 |
| Valuation         | P/E of 25 or less, on last fiscal-year earnings          | P/E of 50 or more, or unprofitable | Stocks                 |

Two more long than short signals make a long bias, two more short than long a short bias; anything else is mixed. A drop of 20% or more from the 52-week high is listed as a risk, not as a reason to buy. The bias is not investment advice.

## Trying a stream outage

Run the UI and the mock API in separate terminals (`npm run dev:ui` and `npm run mock-server`), then stop the mock API for a few seconds while Live Monitor is open. The replay panel shows that the connection is lost, Live Monitor says that its prices are paused, and both recover once the mock API is back. A restarted mock API begins the replay again from 4 November.
